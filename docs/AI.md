# Журнал використання AI-інструментів (ПР 7)

| Задача | Промпт до AI-асистента | Що згенерував асистент | Що виправлено вручну і чому |
| :--- | :--- | :--- | :--- |
| 1. Генерація компонента `CheckoutModal` та `CheckoutForm` | «Створи React-компонент центрального модального вікна оформлення замовлення доставки їжі з полями вулиці, будинку, квартири та перемикачем домофону Так/Ні» | Базову розмітку модального вікна, локальний стан полів та обробку `onSubmit`. | Додано закриття модалки клавішею `Escape`, кліком по затемненому фону (`backdrop`), регулярний вираз для перевірки українського номера телефону `^\+380\d{9}$` та ARIA-атрибути `role="dialog"` і `aria-modal="true"`. |
| 2. Рефакторинг логіки кошика у `StoreContext` | «Винеси стан кошика, теми та модальних вікон у React Context зі збереженням у localStorage» | Провайдер контексту з базовими методами додавання та видалення елементів. | Додано інкремент кількості існуючої страви (`quantity + 1` замість дублювання карток у списку), автоматичне фільтрування позицій з нульовою кількістю та обробку помилок `JSON.parse` через `try/catch`. |
| 3. Пояснення та оптимізація кастомного хука `useFetch` | «Поясни, як уникнути оновлення стану розмонтованого компонента в useEffect при швидкому переході між маршрутами React Router» | Пояснення життєвого циклу `useEffect` і патерну cleanup-функції. | Додано прапорець `isMounted` у функцію очищення `useEffect`, щоб запобігти витоку пам'яті при швидкому перемиканні сторінок каталогу та закладу. |
